## Introduction

A website is a collection of webpages connected to the internet. It can be a personal portfolio, business website, blog, e-commerce store, social platform, or web application.

To build a website, you need to learn how to:

- design the structure
- style the interface
- add interactivity
- connect to a backend
- store data
- deploy it online

## What is a Website?

A website is made of:

- Frontend: what users see and interact with
- Backend: server-side logic and data processing
- Database: where data is stored
- Hosting: place where the website lives online

## Core Technologies

The main technologies for website development are:

- HTML: structure
- CSS: design and layout
- JavaScript: interactivity
- Frameworks: React, Vue, Angular, Next.js
- Backend: Node.js, Python, PHP, Java, Ruby
- Database: MySQL, PostgreSQL, MongoDB
- Hosting: Netlify, Vercel, GitHub Pages, AWS, Firebase

## Programming Languages Used in Website Development

Here are the main programming languages used for websites:

### 1. HTML

Purpose: structure of web pages

Example:

```html
<!DOCTYPE html>
<html>
  <head>
    <title>My Website</title>
  </head>
  <body>
    <h1>Hello World</h1>
  </body>
</html>
```

### 2. CSS

Purpose: visual design and layout

Example:

```css
body {
  font-family: Arial, sans-serif;
  background-color: #f4f4f4;
  color: #333;
}

h1 {
  color: blue;
}
```

### 3. JavaScript

Purpose: client-side interactivity

Example:

```javascript
const button = document.querySelector("button");

button.addEventListener("click", () => {
  alert("Website button clicked!");
});
```

### 4. TypeScript

Purpose: safer JavaScript with types

Example:

```typescript
const userName: string = "Alice";
console.log(`Hello ${userName}`);
```

### 5. Python

Purpose: backend web apps and automation

Example:

```python
print("Hello from Python")
```

### 6. JavaScript / Node.js

Purpose: full-stack development using the same language

Example:

```javascript
const express = require('express');
const app = express();

app.get('/', (req, res) => {
  res.send('Hello from Node.js');
});

app.listen(3000);
```

### 7. PHP

Purpose: dynamic websites and server-side scripting

Example:

```php
<?php
  echo "Hello from PHP";
?>
```

### 8. SQL

Purpose: database management

Example:

```sql
SELECT * FROM users WHERE active = 1;
```
