# Chapter 3: Frontend Development and Frameworks

## 1. Frontend development

Frontend development is the part of web development that focuses on what users see and interact with.

## 2. Common frontend technologies

- HTML
- CSS
- JavaScript
- Bootstrap
- Tailwind CSS
- React
- Next.js
- Vue
- Angular

## 3. Why frameworks matter

Frameworks help structure large projects and simplify development.

## 4. React.js

React is one of the most popular frontend libraries.

### Example

```jsx
function App() {
  return <h1>Hello from React</h1>;
}

export default App;
```

### React concepts

- components
- props
- state
- hooks
- routing
- lifecycle

## 5. Next.js

Next.js is a React framework used for production-level websites and apps.

### Features

- server-side rendering
- static site generation
- API routes
- SEO support
- good performance

## 6. Tailwind CSS

Tailwind is a utility-first CSS framework.

### Example

```html
<div class="bg-blue-500 text-white p-4">Hello Tailwind</div>
```

## 7. Responsive design

Responsive design makes websites look good on phones, tablets, and PCs.

### Learn:

- media queries
- flexible layouts
- fluid typography
- mobile-first design

## 8. Project ideas

- blog UI
- portfolio site
- dashboard interface
- e-commerce homepage
- landing page

## 9. Final note

Frontend development is about building polished and interactive interfaces that provide the best user experience.
