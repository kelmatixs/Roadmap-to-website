# Chapter 6: Security, Authentication, and Deployment

## 1. Security basics

When creating a website, you must protect users and data.

Important topics:

- password hashing
- HTTPS
- input validation
- SQL injection prevention
- XSS protection
- CSRF protection
- secure environment variables

## 2. Authentication

Authentication is the process of verifying a user identity.

Common methods:

- email/password login
- social login
- JWT tokens
- session-based auth

## 3. Authorization

Authorization decides what a logged-in user is allowed to do.

Examples:

- admin can manage users
- editor can edit posts
- viewer can only read content

## 4. Deployment

Deployment is the process of putting a website online.

### Platforms

- Netlify
- Vercel
- GitHub Pages
- Render
- Firebase
- AWS
- DigitalOcean

## 5. Deployment steps

1. Push code to GitHub
2. Connect repository to hosting
3. Configure environment variables
4. Build the project
5. Deploy
6. Test live website

## 6. Final note

A production website requires security, user management, and reliable deployment platforms.
