# Chapter 2: HTML, CSS, and JavaScript Fundamentals

## 1. HTML

HTML is used to create the structure of a webpage.

### Example

```html
<!DOCTYPE html>
<html>
  <head>
    <title>My First Website</title>
  </head>
  <body>
    <h1>Hello, World!</h1>
    <p>This is my first website.</p>
  </body>
</html>
```

### Concepts to learn

- tags
- elements
- attributes
- headings
- paragraphs
- lists
- links
- images
- forms

## 2. CSS

CSS is used for styling and layout.

### Example

```css
body {
  background-color: #f4f4f4;
  font-family: Arial, sans-serif;
}

h1 {
  color: blue;
}
```

### Concepts to learn

- selectors
- colors
- fonts
- margin and padding
- box model
- classes and IDs
- flexbox
- grid
- responsive design

## 3. JavaScript

JavaScript adds interactivity to the website.

### Example

```javascript
const button = document.querySelector("button");

button.addEventListener("click", function () {
  alert("Button clicked!");
});
```

### Concepts to learn

- variables
- functions
- conditionals
- loops
- events
- DOM manipulation
- arrays
- objects
- APIs
- asynchronous programming

## 4. Why these three are important

These are the foundation of all modern websites.

- HTML = structure
- CSS = design
- JavaScript = behavior

## 5. Practical project

Try creating:

- a personal landing page
- a product card
- a contact form
- a simple image gallery

## 6. Final note

Before learning advanced frameworks, master HTML, CSS, and JavaScript. These are the core building blocks of modern web development.
